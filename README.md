# 🌍 Country & City Explorer (Swift)

A simple and growing iOS application that lets users browse **countries** and their **respective cities**.  
This project is still in its early stages, and will evolve as new features are added.

---

## ✨ Current Features
- 🗺️ List of countries  
- 🏙️ Cities mapped to each country  
- 📱 Clean and simple Swift implementation  

---

## 🚧 Upcoming Features / Roadmap
I plan to introduce several improvements as the project develops:

- ⛅ **Weather per city**  
  View real-time weather information for any selected city.

- 📊 **More detailed city data**  
  Population, coordinates, timezone, and more.

- 🌐 **API integration**  
  Fetch live data instead of relying on static lists.

- 🎨 **Improved UI and UX**  
  Better layout, icons, animations.
